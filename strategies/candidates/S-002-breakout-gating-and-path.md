# S-002 — 突破信号、NEMT 许可与持仓路径的可分离研究

**研究编号：** S-002  
**版本：** 0.1（2026-10-26）  
**状态：** CONJECTURE / EVIDENCE-REVIEW；尚无新版本回测结果，不属于可交易策略  
**关联家族：** F-BRK（突破）、F-TRND（趋势）、F-NONE（观望）  
**市场状态候选：** R-01 趋势形成、R-04 波动压缩后突破、R-05 突破失败、R-07 不确定性  
**研究原则：** 将“出现机会”“许可交易”“能否入场”和“持仓管理”作为四个不同环节，不再把一条联合规则当作单一不可拆分策略。

## 1. 新证据与修订动机

数据来自理论仓库已保存的报告，不涉及本次重新运行行情：

- [2021 冻结窗口 E1–E5](../../experiments/reports/20261026-2021-frozen-battery.md)：20 日 Donchian 共 **73 个突破候选**，NEMT 联合许可 **73 通过 / 0 拒绝**，熵门槛也 **0 拒绝**；Donchian-only 与 Donchian+NEMT 单账户收益均为 **+17.1344%**。73 个独立虚拟候选的净风险单位均值为 **-0.2494R**，但实际单账户只完成 **11 笔交易**，收益为正。说明事件全集与持仓路径的统计对象不同；**不能只靠两者均值差断言持仓约束的因果增益**。
- [2023 冻结窗口 E1–E5](../../experiments/reports/20261026-2023-frozen-battery.md)：NEMT 拒绝 **16/54 个** Donchian 事件，筛选增量 `Delta_R=-8.2719`（区间含零）；Donchian-only **+43.5900%**，Donchian+NEMT **+40.8920%**。被拒事件中含极端大赢家，不能称为已稳定识别风险。
- [2025 v5.2.6 探索性诊断](../../experiments/reports/20261026-v526-incremental-information.md)：Donchian 候选 **69 个**，其中 **66 个平仓、3 个期末删失**；在已平仓事件中，NEMT 许可 47 个、拒绝 19 个，`Delta_R≈+0.3546`，但两个条件组平均 R 均为负且去重结果 `INCONCLUSIVE`。Donchian-only **-11.2108%**，联合许可 **-6.3316%**。**19 不是完整的 69 个候选的全部拒绝数**：有 3 个删失候选，不能把 `19/69` 当成严格的门槛拒绝率。
- [2024 冻结协议](../../experiments/preregistration/2024-confirmatory-freeze.md) 已于本研究变更前提交。它只冻结既定 E1–E5，且声明兄弟策略族观察污染。**不得把本 S-002 变体事后加入其确认性实验**。

**目前的证据支持重新分解问题、优先审查冗余过滤与持仓路径；不支持宣称 20 日、55 日、NEMT 或某个新路由必定更赚钱。** 三个年度单账户仅 11 / 13 / 18 笔，右尾大赢家与年份选择高度影响结论。

## 2. 研究模型：四层独立定义

```text
Opportunity(t):  用历史已完成K线确定“潜在突破事件”，不看账户仓位
Gate(t):         对同一 Opportunity(t) 给出 NEMT 等许可或拒绝（含原因）
Eligibility(t):  当下是否允许开仓：空仓/未冷却/风险与数据有效/无冲突
Playbook(t):     已有仓位的持有、反向通道、保护止损、越价风险与暂停分支
```

- **Opportunity ≠ Order**：同一趋势中可能有多个连续突破事件，但单账户已有仓位时它们只是观察，不自动重复建仓。
- **Gate ≠ Prediction proof**：NEMT 从价格动量与价格分箱熵构造，与 Donchian 有共源信息；没有拒绝事件时不可能估计许可的选择增量。
- **Eligibility ≠ Gate**：即使信号与许可同时满足，也可能因为已有仓位、风险超限、费用或数据异常而没有新订单。
- **Playbook ≠ 事后解释**：入场时的策略 ID、风险预算、计划版本与退出分支必须冻结，后续状态变化只按约定条件处理。

### 计划审计必须区分的字段

每次候选机会记录：`event_id`、市场/周期、已完成的信号时点、突破方向、历史窗口参数、`psi` / `S` 与 gate 结果、持仓/风险 eligibility、计划版本、若未入场其拒绝原因、实际订单状态、执行和退出原因、数据与模型指纹、期末删失状态。

**禁止**根据一笔结果倒过来修改市场状态、把未执行的独立虚拟事件计为真实交易、把因仓位占用跳过的机会归功于 NEMT 许可。

## 5. 下一轮可证伪的问题与对照

**Q1：2021 的 0/73 拒绝是否说明 NEMT 在部分状态下是冗余过滤器？**

- `H0`：在冻结的独立评估状态集合中，加入 NEMT 并不稳定改变突破候选的净 R 分布或单账户风险调整表现。
- `H1`：许可层在某些**事前可识别的状态**下稳定增加条件信息，并在新的独立数据中优于简单动量或无许可的基准。
- 先报告 gate 的**全候选拒绝率**（连同期末删失状态）、许可方向重合率、`psi` 与熵的共同分布，再比较真正有对照组的区间。

**Q2：原先误以为 NEMT 在筛选，是否其实是账户单持仓规则在筛选？**

- 用相同 `Opportunity` 事件 ID 标记“信号”“gate许可”“空仓资格”“实际入场”；通过**配对事件级**和**单账户路径级**两个层次比较。二者分母和估计目标不同，不得直接相减得出净因果贡献。
- 如果想检验去除/修改单持仓规则，必须设计一个真实可执行且风险约束相等的单独组合对照；不能把无限重叠的虚拟交易简单加总成收益率。

**Q3：20日/55日差异源自更慢入场还是更长退出？**

- 未来另开正交的 2×2 实验：入口 120/330 × 退出 60/120，固定 NEMT gate、风险预算、执行假设和数据窗口；每个新实验臂作为新版本，不得混用先前冻结实验的结论。

### 停止条件

拒绝率为零、关键组样本不足、无法将分类状态定义在决策时点、交易结果主要依赖几个极端赢家或多重测试未受控时，标 `INCONCLUSIVE` / `BLOCKED`。不得自动晋级到 PAPER / LIVE，亦不应因为已有数据每周增加就滚动调参。

# SOFT-STATE-SIZING-001 冻结设计

## 研究问题

在固定价格趋势方向、退出规则和只做多约束下，成交量与 NEMT 状态是应当删除交易的硬门，还是只应调节仓位的软信息？

软仓位定义为：

$$
q_t=q_{base}\,f_{volume}\,f_{NEMT}\,f_{volatility},
$$

其中状态因子只在 $[0.5,1.25]$ 内调节仓位，不得轻易把仓位降到零。基线已按 ATR 风险归一化，因此本实验令 $f_{volatility}=1$，避免重复计算波动率。

## 固定项

- 资产：BTC、ETH、BNB、SOL；4 小时 K 线；
- 方向：long-only；
- 入场：120 根突破；退出：60 根反向通道；
- 费用、滑点、实际历史资金费率、初始保护止损和风险预算固定；
- 2023–2024 为冻结时间留出窗口；它是 temporal holdout，不声称为完整独立样本外复现。

## 实验臂

| 臂 | 状态使用方式 |
| --- | --- |
| A | 纯价格趋势基线 |
| B | Wyckoff SOS 成交量硬过滤 |
| C | NEMT critical_up 硬过滤 |
| D | 成交量软评分 |
| E | NEMT 软评分 |
| F | 成交量 + NEMT 联合软评分 |

## 晋级门槛

状态层必须同时：

1. 增加冻结时间留出净利润；
2. 保留历史前十大赢家中的绝大多数；
3. 严格减少震荡期止损簇；
4. 最大回撤不超过基线的 1.10 倍；
5. 改善不能只来自单笔赢家，也不能只是平均提高仓位。

任一硬门失败即 `REJECT`。提高胜率但降低尾部利润不构成晋级。

## 最低输出

逐 K 线保存相对成交量、Z-score、OBV 趋势、Spring/Upthrust/SOS/SOW、NEMT entropy/psi/phase、原始与最终仓位、各因子和硬门反事实；逐笔保存持有期、成本、MFE/MAE、净收益和退出路径。

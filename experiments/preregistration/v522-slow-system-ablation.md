## 1. 已确认的结构缺陷：55 日分支被 20 日优先级遮蔽

在同一方向、同一时点、同一历史样本的充分窗口下，定义：

```text
U20(t) = max(H[t-120], ..., H[t-1])
U55(t) = max(H[t-330], ..., H[t-1])
L20(t) = min(L[t-120], ..., L[t-1])
L55(t) = min(L[t-330], ..., L[t-1])
```

由于 `U55(t) ≥ U20(t)` 且 `L55(t) ≤ L20(t)`，所以：

- `C_t > U55(t)` 必然蕴含 `C_t > U20(t)`；
- `C_t < L55(t)` 必然蕴含 `C_t < L20(t)`。

因此 **55 日突破事件是 20 日突破事件的子集**。在同一 NEMT 方向许可条件下，若每次先选择满足条件的 20 日系统、再尝试 55 日系统，则 55 日系统永远不能被独立选中。该问题是逻辑可达性，不是市场统计规律。

### 已核对的实际实现与结果

- [Emergenzix v5.2 研究实现](https://github.com/huliye24/emergenzix/blob/d6962bedb9cf18e927ac9ae768e55eb4a57ea0d9/backend/emergenzix_api/nemt_strategy/v52_turtle_cli.py)：`breakout(bars, decision_index, 120/330)` 使用决策 K 线**以前**的历史窗；先判断 `fast == direction` 再判断 `slow == direction`，且以当前决策之前的已完成 K 线给下一根开盘生成动作。就上述审计范围而言，未发现 v5.2 突破窗口包含自身 K 线的错误。
- [2025 原始报告](https://github.com/huliye24/emergenzix/blob/d6962bedb9cf18e927ac9ae768e55eb4a57ea0d9/docs/reports/NEMT_V52_CONTINUOUS_2025.json)：共 18 笔已记载交易，18 笔属于 `system_1_20d`，0 笔属于 `system_2_55d`，总收益约 -6.33%。**不能将该结果描述为“55 日系统已验证失败”**。
- `accepted_breakouts=18` 不等于所有候选事件；历史报告同时记录 191 个 NEMT 定向候选。统计单元必须区分候选、许可、成交与持仓。

上述结论是对当前可见源代码与记录的**静态审计**；本次没有重新运行 AWS 实验、验证逐笔成交或独立复现收益。

## 2. 本步研究问题

**Q1：** 将 v5.2 的优先级双系统改为 **55 日独立运行**，是否会改变候选数量与短期止损比例？

**H0（比较假设）：** 在预先指定的评价区间，55 日独立系统的短期止损比例不低于原 20 日优先系统；有限交易样本不足时只报告区间与不确定性，不作显著性结论。

**H1：** 55 日独立系统可能降低进入快速失败交易的频率；这**不等于**假定其总收益更高。

## 3. 冻结的两个研究臂（不可同次调参择优）

| 项目 | A：原始 v5.2 对照 | B：55 日独立系统 v5.2.2 |
| --- | --- | --- |
| 入场阈值 | 历史 120 根 4h K 线（先选快速） | 历史 330 根 4h K 线；不启用快速回退 |
| 退出通道 | 历史 60 根 4h K 线 | 历史 120 根 4h K 线 |
| NEMT 许可方向 | 已完成 `t` 的 critical_up/down | 完全相同 |
| 执行时点 | `t` 收盘后判断；`t+1` 开盘基线 | 完全相同 |
| ATR（N） | 120 根 4h K 线 | 完全相同 |
| 初始保护 | 2N | 完全相同 |
| 单笔风险上限 | 账户权益的 1% | 完全相同 |
| 杠杆上限 | 3 倍 | 完全相同 |
| 其他 | 单账户、不重叠持仓、不加仓、无固定止盈 | 完全相同 |
| 费率与滑点 | 单边 5 bps 手续费、2 bps 滑点 | 完全相同 |

**因果归因限制：** A/B 同时改变入场阈值与退出通道，若结果不同，**不能**将其全部归因于“慢速入场减少假突破”。如需隔离单一变量，应在单独、后续的预注册协议中固定相同退出通道设计新实验臂，不允许看见结果后临时加入。

## 4. 观察指标与裁决规则

- **首要诊断指标**：开仓后前 **42 根已完成 4h K 线（7 自然日）内**以 `2N_stop` 退出的交易数 / 完整可观察的入场交易数（早于第 42 根到达评价边界的未结束交易须标注删失）。这是“早期止损代理”，**不能直接当作已证实的假突破真值**。
- **同时报告分母**：NEMT 定向事件数、Donchian 同向突破数、实际入场数、可观察到 42 根的入场数、盈利/亏损/未关闭数。
- **次要结果**：成本后总收益、最大回撤、盈亏比、盈利因子、单笔净 R、持仓天数、按方向与按时段分组、费用和滑点敏感性（敏感性范围需在首次检验前额外锁定）。
- **判断**：不能因 B 交易数量少就直接宣称优于 A。缺少足够交易或差异不稳定时允许 `INCONCLUSIVE`；若代码不符合规则则 `BLOCKED`；成功实现实验也不等于策略准入。

## 5. 污染控制与证据上限

1. **2025 年已被 v5-alpha、v5.1、v5.2 反复查看**，未来在 2025 年复跑 B 只能作为诊断性再分析（`EXPLORATORY`），不得再称它是独立的盲样本外验证。
2. 确认性检验需先审核数据是否真的未被先前策略选择使用，并**在计算前**冻结具体起止日期、市场、数据版本/校验、程序提交、执行成本与验收标准；若找不到未使用的历史留出集，应采用前瞻性 PAPER/影子观察。
3. 不因为 B 的首次结果不佳就调整 330、120、2N 或其他门槛。不允许挑选看起来最好的历史窗口、方向或月份。
4. 任何估计都应附样本量和不确定性。BTC 单资产表现无法证明跨市场有效性；缺少真实资金费率、滑点压力或强平模拟时必须继续标注限制。

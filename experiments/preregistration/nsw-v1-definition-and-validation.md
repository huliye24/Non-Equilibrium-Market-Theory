# NEMT谱宽 NSW-v1：定义审查、合成验证与BTC小实验计划

> 状态：设计冻结候选稿，尚未运行。研究用途，不产生交易权限。

## 1. 为什么不能直接继续测试

2026-10-17 的数学实验已经发现，旧二阶矩谱宽对 ψ 构造、谱估计器和窗口
不稳健，且在控制当前波动率后没有显示未来波动率增量。2026-10-30 的
BTC 2017–2018 小实验进一步发现，旧指标的低分位穿越没有稳定识别后续
区间扩张。

因此，本计划不是“拯救谱宽”，也不允许给旧公式换名后继续调参。首先必须
回答旧量到底测量了什么，再判断是否存在值得进入真实市场实验的新定义。

本计划服从已有的[稳健观测量筛选预注册](follow-up-20261017/05-observation-robustness.md)。
若两份文件冲突，以更严格、且更早冻结的判据为准；真实BTC数据不得用于在
候选定义之间挑选赢家。

## 2. 名称与版本冻结

### 2.1 NSW-v0：历史旧指标

旧实现为正频率功率分布的归一化均方根频率：

```text
p_k = P_k / ΣP_k
NSW-v0 = sqrt(Σ p_k f_k²) / f_Nyquist
```

由恒等式 `E[f²] = Var(f) + E[f]²` 可知，NSW-v0 同时混合了频谱中心和
中心周围的离散程度。它不是严格的中心矩谱宽。

- 用户可见历史名称：`NEMT谱宽 NSW-v0`。
- 研究字段：`nemt_spectral_rms_frequency_v0`。
- 状态：`EXPERIMENTAL_FAILED_ROBUSTNESS`。
- 用途：保留复现和对照，不得覆盖、重命名为v1或进入标准K线图。

### 2.2 NSW-v1：真正的中心矩谱宽候选

在长度为 `W` 的已完成对数收益窗口上，先去均值，再用冻结的谱估计器得到
单边正频率功率 `P_k`。若总功率低于数值有效门，则输出 `undefined`，不能把
静止序列错误标成“零谱宽”。

```text
p_k = P_k / ΣP_k
NSCEN-v1 = Σ p_k f_k / f_Nyquist
NSW-v1 = sqrt(Σ p_k (f_k - Σp_j f_j)²) / f_Nyquist
```

- `NSCEN-v1`：归一化谱质心，表示能量主要位于低频还是高频。
- `NSW-v1`：质心周围的频率离散程度，表示窄带还是宽带。
- `NSW-v1` 不表示价格运动幅度，也不直接表示“市场压缩”。

### 2.3 NSE-v1：谱能量控制量

```text
NSE-v1 = (1/W) Σ(r_t - mean(r))²
```

采用与功率谱一致的归一化，使其通过Parseval等式与频域总功率相等。NSE-v1
本质上是窗口实现方差，不宣称拥有超越实现波动率的独特信息。它的作用是把
“运动有多大”与“频率结构是什么”分开，并作为传统波动率控制量。

### 2.4 频谱集中度不冒充谱宽

频谱熵 `Hspec`、高频尾部质量 `Tail20`、逆参与率等属于独立候选观测量。
它们不得统称为NSW。若后续需要一个“频谱集中度”，单独使用 `NSC-v1`
命名，并通过既有实验五的候选量筛选。

## 3. 冻结的谱估计规范

主定义使用：

- 输入：已完成K线的对数收益；不使用未来数据；
- 去趋势：仅去窗口均值，不做使用未来点的滤波；
- 主估计器：Hann窗 Welch；
- 主窗口：`W=128`；
- Welch段长：64；重叠：32；
- FFT长度：64；
- 去除DC项，仅保留正频率；
- 功率归一化必须满足Parseval数值检查；
- 总能量不高于浮点门槛时，质心和谱宽均为 `undefined`；
- 缺口、重复、未完成K线或跨越缺口的窗口全部排除。

稳健性设置不用于挑选主定义，只用于压力测试：periodogram、Welch、sine
multitaper；窗口64/128/256；矩形/Hann边界处理。不得在看到BTC结果后改变
主定义。

## 4. 阶段A：确定性合成语义测试

阶段A不使用市场数据，不使用GPU，不训练模型。每条序列固定长度、采样率和
振幅，验证公式是否具有其名称所声称的数学语义。

| 场景 | 冻结变换 | 必须观察到的结果 |
| --- | --- | --- |
| 单一正弦 | 振幅乘0.5、2、10 | NSE按振幅平方变化；NSCEN、NSW近似不变 |
| 频率平移 | 低频正弦改为高频正弦 | NSCEN改变；理想窄带NSW近似不变 |
| 双频分离 | 两个等功率频率逐步拉开 | NSW单调增加 |
| 白噪声 | 固定seed的宽频噪声 | NSW显著高于单一正弦 |
| Chirp | 冻结扫频范围逐步扩大 | NSW随扫频范围单调增加 |
| 零/常数收益 | 总能量为零 | NSCEN和NSW为undefined，不得输出0 |
| 振幅调制 | 频率不变、振幅缓慢变化 | NSE变化；NSW不应被系统性解释为波动率 |

阶段A全部断言通过才进入阶段B。任一核心断言失败，先修公式或实现并产生新
版本；不得进入BTC实验。

## 5. 阶段B：随机合成稳健性实验

直接复用既有实验五的四类过程与30个seed：GARCH状态切换、ARFIMA/GARCH、
Jump-diffusion、Chirp加有色噪声。NSW-v1作为新增候选与NSW-v0、`Hspec`、
谱质心、`Tail20`和IPR同场比较。

主判据沿用既有冻结标准：

- 跨估计器/窗口最差中位Spearman `≥0.75`；
- 重测可靠性ICC中位数 `≥0.70`；
- 四类过程至少三类对已知状态变化方向正确，且 `|ρ|≥0.30` 或
  `|Cliff δ|≥0.33`；
- leave-seed-out 95%区间仍满足方向要求；
- NLS演化是否增加信息单独报告，不把“经过NLS”默认视为优势。

NSW-v1必须同时通过前四项才允许进入阶段C。若 `Hspec` 或 `Tail20`通过而
NSW-v1失败，应接受“谱宽不是主观测量”，不得降低标准。

## 6. 阶段C：BTC 2017–2018小实验

只有阶段A、B通过后才运行。数据仍使用固定S3 Manifest、Binance BTCUSDT
现货、15m/1h/4h，缺口规则与上一轮一致。

### 6.1 主问题

NSW-v1在控制当前能量NSE-v1后，是否包含后续波动变化的增量信息？

主结果使用连续目标，避免先用任意阈值把市场二分：

```text
Y_t = log(RV_future_one_day / RV_past_one_day)
```

其中过去窗口在决策时完整可见，未来窗口仅用于标签。主要报告：

- NSW-v1与Y的Spearman相关；
- 控制 `log(NSE-v1)`、布林带宽度和ATR后的系数及区间；
- 相对仅含传统波动量基准的样本外 `R²` 增量；
- 按月块bootstrap的95%区间。

若连续目标没有增量，不再通过调整事件阈值寻找“有效信号”。

### 6.2 次要事件问题

事件仅作可视化和解释，不作为选择主定义的依据：

```text
低能量：NSE-v1 <= 训练期20%分位
窄谱：NSW-v1 <= 训练期20%分位
候选状态：两者首次同时成立
```

- 阈值只用训练期估计并冻结到选择期/测试期；
- 一个状态持续期间只记录首次进入；
- 退出后必须等待一个完整预测期才能产生新事件；
- 训练、选择、测试边界使用一个预测期purge和embargo；
- 不允许重叠事件共享同一未来标签；
- 同时报告单独低NSE、单独低NSW和二者交集，防止把能量效果错误归给谱宽。

### 6.3 公平基准

所有指标使用相同K线、时间点、历史可见范围、滚动窗口、目标、purge、
embargo和评价指标。基准为：

1. NSE-v1/实现方差；
2. 布林带宽度；
3. 归一化ATR；
4. 谱质心NSCEN-v1；
5. 基准 + NSW-v1。

只有第5项相对第1–3项在多数未见窗口产生正的样本外增量，才能讨论NSW的
独立价值。

## 7. 小实验滚动与防泄漏规则

- 试运行：6个月训练、2个月选择、2个月未见测试、步长2个月；
- 正式验证仍为18+3+3，试运行不能替代正式验证；
- 标准化、分位数、缺失处理和模型拟合只能使用当时可见数据；
- 目标窗口跨越数据缺口、月度边界purge区或数据末端时删除；
- 选择期只允许在预注册候选之间选择，不允许创造新特征；
- 测试期结果一次性生成，失败后不得把同一期间重新称为未见测试；
- 15m相邻样本使用按月块bootstrap；事件分析使用非重叠事件簇；
- 报告样本数、有效独立块数和事件数，不能只报告K线行数。

## 8. 阶段C晋级与停止条件

### 8.1 进入完整18+3+3的最低条件

必须同时满足：

1. NSW-v1已通过阶段A全部语义断言和阶段B稳健性门；
2. 基准+NSW相对传统基准的样本外 `R²` 增量在多数窗口为正；
3. 增量中位数为正，月块bootstrap 95%区间不显示稳定负效应；
4. 删除最大波动月份后方向不反转；
5. 参数不频繁跳变，且没有单一周期承担全部结论；
6. Python与MATLAB固定样本的NSW/NSE/NSCEN误差在冻结容差内。

### 8.2 停止条件

满足任一项即停止NSW晋级，不继续调参：

- 阶段A语义失败；
- 阶段B稳健性门失败；
- BTC连续目标无增量，而事件结果仅靠阈值变化出现；
- 结果完全由NSE解释，NSW没有独立贡献；
- 只有一个窗口、一个周期或少数极端月份支持结论。

停止不等于删除。失败版本、代码、Manifest、参数和报告必须保留。

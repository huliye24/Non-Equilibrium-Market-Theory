# 低频化 + 顺势加仓 + 跨币对冲：三臂冻结声明

**类型**：策略结构调整实验（先冻结，后计算）
**冻结时间**：2026-10-26
**实现**：Emergenzix（`--entry-bars` / `--exit-bars` / `--slices` / `--stop-mult`）
**证据等级**：`EXPLORATORY`

## 1. 用户的假设（原文）

> 「把时间轴拉长，只有少数趋势是有效趋势，而大部分趋势不值得开单，而这些少数趋势
> 值得增加仓位，顺势加仓，而出现逆势，应该给相似币种去做对冲，开相反方向的仓位，
> 保证收益，所以我们需要调整策略，减少交易频次。」

拆成三个可独立检验的命题：

| 编号 | 命题 | 操作化定义 |
| --- | --- | --- |
| **A** | 拉长周期后只有少数趋势有效，应减少交易频次 | 入场通道 120 → **240 / 480 根 4h**（20/40 天） |
| **B** | 少数有效趋势应加大仓位、顺势加仓 | 分批风险切片从等权改为**递增 25%/35%/40%**，且放宽止损到 4N 以便活着加仓 |
| **C** | 逆势时用相似币种反向对冲，「保证收益」 | 跨资产配对：主腿与对冲腿反向同风险 |

## 2. 评估标准：只看凯利上限

上一轮已证明：`年化增长 = E[log(1 + f·R)]`，在 R0 基线上最优 `f* = 3.5%`，
年化上限 **+14.64%**。方差拖累吃掉了算术期望的 61%。

因此本轮**不以期末权益或单年收益排序**，而以下面这个量排序：

```text
凯利上限 g(f*) = max_f E[log(1 + f·R)]
```

理由：降低方差的策略即使降低收益率也可能提高 `g(f*)`——这正是对冲在数学上
唯一可能的价值来源。反过来，提高收益但放大方差的策略可能降低 `g(f*)`。

## 4. 命题 C（对冲）的处置方式

**本轮不做完整回测，只做可行性数学检验。** 理由：对冲是**把方向性风险换成价差风险**，
它不在原有的单资产引擎语义内，需要双账本；而且必须先回答"它是否可能提高凯利上限"。

检验内容：

1. 10 个币两两之间的 4h 与日收益相关系数（2022–2025）；
2. 用相关系数估计"对冲后残余方差"，代入 `g(f) = E[log(1+f·R)]` 的近似式
   `g ≈ f·μ − (f²/2)·σ²`，看在何种相关系数下 `g` 会上升；
3. 明确写出"保证收益"在数学上不成立的条件。

## 5. 必须声明

1. **"保证收益"在数学上不成立。** 对冲锁定的是**价差**，不是收益：
   两条腿各付一次手续费与滑点，相关性强时价差小、成本占比高；
   相关性下降时对冲失效，两条腿可能同时亏损（2022 年多数币同跌，方向对冲无效）。
2. 提高单笔风险不会提高凯利增长（已证：`f > 3.5%` 后 `g` 下降）。
3. **不授权 PAPER / TESTNET / LIVE。**

# S-004.D — 市场环境与方向不对称研究协议

**日期**：2026-10-26
**阶段**：EXPLORATORY（2022–2025 已被反复观察；本协议为防止再犯"调参追赢家"）
**前置**：S-004.A（硬过滤 0/24）、S-004.A.2（事件级 A/B）、S-004.A.3.2（特征诊断，`INCONCLUSIVE`）
**执行**：仅离线研究；不改交易入口、不改风险参数、不创建订单

## 0. 为什么要有这一层

前三项研究都在**单笔交易**层面找差异，全部失败。失败的原因不是"没有规律"，
而是**问错了层面**：一笔盈利交易的特征，可能只是它恰好落在一次市场级上涨里。

本协议把研究单位从"单笔交易"上移到**市场环境**，并同时回答三个层面：

| 层面 | 新研究问题 |
| --- | --- |
| 市场环境 | 极端赢家是否集中在持续性牛市或高动量阶段？ |
| 交易方向 | 多头和空头是否应具有不同的风险预算？ |
| 组合风险 | 不同币种的盈利是否来自同一次市场级上涨？ |

## 1. 市场基准与因果边界

- 基准：**BTCUSDT 现货 4h**（唯一基准，不按结果挑选基准）
- 每个候选信号在**决策时点**只允许看到满足 `t_open + 4h ≤ cutoff` 的完整 BTC K 线
- 所有环境变量只由这些已完成 K 线计算；**不得使用候选自身的未来价格、退出原因、盈亏**
- 缺口/不足 → 该候选环境标记 `UNAVAILABLE` 并计入缺失率，不填值

## 2. 冻结的环境变量与阈值（在看任何结果之前写死）

| 变量 | 定义（截至决策时点） | 分档 |
| --- | --- | --- |
| `btc_trend` | BTC 近 **180 根**（30 天）收益 | `UP` > +5%、`DOWN` < −5%、`FLAT` 其余 |
| `btc_trend_long` | BTC 近 **540 根**（90 天）收益 | `UP` > +10%、`DOWN` < −10%、`FLAT` 其余 |
| `btc_vol` | 近 180 根对数收益的总体标准差 ÷ 过去约 1 年（1620 根）同口径滚动标准差的中位数 | `LOW` < 0.8、`HIGH` > 1.2、`NORMAL` 其余 |
| `btc_drawdown` | （近 540 根最高 high − 最新 close）÷ 该最高 high | `SHALLOW` < 5%、`DEEP` > 20%、`MID` 其余 |

主环境格 = `btc_trend` × `btc_vol`（3×3 = 9 格）；
`btc_trend_long` 与 `btc_drawdown` 作为**次要分层**，用于检验主结论是否被长周期或回撤状态解释。

**阈值不因结果修改。** 若发现阈值不佳，只能另开新协议，不得回改本协议。

## 3. 事件与分组

- 事件集：**与 A.2 / A.3.2 完全相同的 2,356 个候选**（可重叠、假设性、不可当组合）
- 每个事件记录：`candidate_id`、`symbol`、`year`、`direction`、`net_R`、
  `week_cluster`、四个环境变量与分档、`env_status`
- 不设 top1%/top5% 为主分析：**主分析用全部候选的净 R 分布**，避免 24 笔小样本支配结论

## 4. 必须报告

1. 每个环境格 × 方向的样本数、缺失率、净 R 中位数、四分位距、合计 R、胜率；
2. **多空不对称**：同环境格内 `median(R_long) − median(R_short)`；
3. **逐年方向一致性**：2022–2025 四年中该差异符号一致的年份数；
4. **不确定性**：按 ISO 周聚类的块自助法（2000 次），报 95% 区间；聚类数不足则写 `INCONCLUSIVE`；
5. **组合层面**：按周汇总的总 R，报告前 5 周占比、正周比例、
   以及各币种周度 R 的两两相关（检验"多币盈利是否来自同一次上涨"）；
6. 单独报告 2025 年（已知差年）与 2024 年（已知好年），检验结论是否被单一年份支配。

## 5. 判定规则（事先写死）

| 问题 | 判定为"有证据"的条件 | 否则 |
| --- | --- | --- |
| 多空差异化风险预算 | 同环境格内 `median(R_long) − median(R_short)` 的聚类 95% CI 排除 0，**且**四年中 ≥3 年符号一致 | `INCONCLUSIVE` |
| 某环境格值得优先参与 | 该格 n ≥ 50、净 R 中位 > 0，**且**聚类 CI 下界 > 0，**且** ≥3 年为正 | `INCONCLUSIVE` |
| 仅在该环境下考虑对冲 | 该环境下空头净 R 中位 ≥ 0 且 ≥3 年不为负（即空头不是纯成本） | 不在该环境考虑对冲 |
| 组合分散是否只是同一次上涨 | 若前 5 周合计 > 50% 总 R，或币种周度 R 平均相关 > 0.5，则视为**同一行情**，不得记作独立样本 | 视为可分散 |

**任一判定未达标即 `INCONCLUSIVE`，不得用"看起来有差异"替代。**

## 6. 归档要求

- 事件级 CSV（含环境标签与 `env_status`）
- 统计 JSON（含每格、每年、自助法区间、组合层面指标）
- 报告明确标注 `EXPLORATORY` 与"等待新独立行情验证"的部分
- 前四项早期特征研究（A / A.2 / A.3 / A.3.2）在本报告中统一归档为 `INCONCLUSIVE`

## 7. 禁止事项

1. 不得用已知 24 笔赢家的特征反推新阈值；
2. 不得在同一 2022–2025 数据上宣称"验证成功"；
3. 不得把可重叠候选的合计 R 当作可实现组合收益；
4. 不得据此改任何交易入口或风险参数、不得创建任何订单。
